Firmware updates

KestrelOne updates over USB, straight from this page. Nothing to download and no tools to install — your browser talks to the device directly.

Latest version Checking…

Your device shows the version it is running on its own web page, under Status. If they match, there is nothing to do.

  1. ConnectPlug KestrelOne into this computer with a USB-C cable. It must be a data cable — a charge-only lead powers the device but the browser will not see it.
  2. UpdatePress the button below and choose the KestrelOne serial port.
  3. ReconnectWhen it finishes, join the KestrelOne WiFi network again from your phone or tablet. The default password is kestrelone.
This browser cannot talk to USB devices. Use Chrome or Edge on a desktop computer — Safari and Firefox do not support it, and nor do phones or tablets. Serial access was blocked. This page must be opened over HTTPS.

An update keeps your settings and WiFi credentials. Ticking Erase device wipes them and returns it to factory defaults.

After the update

When the update finishes, this page reads the device back to confirm it restarted and is running the new version. That is worth more than a progress bar reaching the end: it shows the firmware booted, not just that it was written.

Nothing to report yet — run an update, or press Check this device to see what a connected KestrelOne is running.

Nothing is uploaded and nothing is stored. The serial shown is your device's own identifier, printed on its startup message — worth noting down if you ever need to ask about your particular unit.

If something goes wrong

The browser does not list any serial port

Almost always the cable. Many USB-C leads carry power only; the device will light up but never appear to the computer. Try a different cable before anything else. If it still does not appear, unplug it, wait a few seconds and plug it back in.

The update failed part-way through

Nothing is broken. The device keeps its previous firmware until a new one is written completely, and an interrupted write can simply be run again. Unplug it, plug it back in, and press Update once more.

It updated, but my EFB no longer sees traffic

Rejoin the KestrelOne WiFi network from your tablet — phones and tablets usually drop back to a remembered network while the device restarts. Then check the device's own page under Status that it is receiving.

Can I go back to an older version?

Yes, though this page only ever offers the latest. Older releases are kept and can be flashed with the same tool if you need one; get in touch rather than guessing, so we can work out what went wrong with the new one.

KestrelOne is a receive-only device. It shows you nearby aircraft; it does not transmit and does not make you visible to anyone else.
